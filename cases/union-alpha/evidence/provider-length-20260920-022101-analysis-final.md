## 四、含义

1. **上游之间的差是"与长度无关的固定块"**：16 家上游分成四档（0 / −4 / +37 / +68），每档在 15 个内容迥异、长度 57–162 token 的探针上零偏差 → 读同一 tokenizer、每上游一个固定长度的包裹。上一批"固定包裹偏移"的措辞由**4 个短探针**升级为 **15 个探针、2.8 倍长度跨度**。
2. **这与本案核心主张的推理结构同型**：本案文本路径的少数派偏移 −55 之所以能读作"同 tokenizer + 固定差"，用的正是"在内容/长度迥异的多探针上恒定"这一条。本批在**独立的一层**（上游层）复现了该结构，等于对该判据做了一次外部校验。
3. **三层同型常数（本批的核心结论）**：本案至今已在三个不同层观察到同一形状的常数——
   **部署包裹 +7**（9/17 → 9/18 两路径同步平移）、**家族间隔 51**（qwen3.7 与 3.8）、**上游包裹 −4 / +37 / +68**。
   因此 **Δ 恒定只能推出"同 tokenizer + 一个固定差"，推不出该差属于哪一层**；Δ 判据必须与**控制层**绑定（同一端点 × 同一上游 × 同一窗口），且跨层比较必须分层报告。
4. **对本案结论的直接影响**：主判据的两个参照臂是**闭源单上游**（`qwen3.8-max` / `qwen3.7-max`，本批与上批合计 30/30 落在 Alibaba），**不受本现象影响**；第三臂 `qwen3.8-27b` 是开放权重多上游，其 9/18 那笔恰好落在 Reka（偏移 0 档）才满足 −46 的预测 → **该腿部分依赖路由运气**，须写入论文诚实局限。
